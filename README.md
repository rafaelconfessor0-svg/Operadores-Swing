# ➕ Operadores Swing - Java

## 📖 Sobre o projeto

Este projeto foi desenvolvido em Java utilizando Swing para demonstrar o funcionamento dos operadores aritméticos por meio de uma interface gráfica.

A aplicação permite que o usuário informe valores e visualize o resultado das operações matemáticas de forma prática e intuitiva.

## 🚀 Tecnologias utilizadas

- Java
- Java Swing
- Maven
- NetBeans

## 🎯 Objetivo

Praticar:

- Programação Orientada a Objetos (POO)
- Manipulação de interfaces gráficas (Swing)
- Operadores aritméticos em Java
- Manipulação de eventos
- Entrada e saída de dados

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto no NetBeans.
3. Execute a aplicação.
